Technical Documentation: Energy Forecast

Технічна документація: Енергопрогноз

Abstract

Анотація

This system provides short-term forecasting of electricity consumption based on a 30-day history and weather factors.

Дана система забезпечує короткострокове прогнозування споживання електроенергії на основі 30-денної історії та погодних чинників.

Model Logic

Логіка моделі

The model predicts 24 hours of load by combining data with number of days(30), weather parameters (7) and hours(24).

Модель прогнозує 24 години навантаження, поєднуючи дані кількості днів(30), параметрів погоди і т.д.(7) та годин(24).

Input Vector: 30 * 31"24 + 7" = 930 + 7"for next day" = 937 parameters Вектор входу: 30 * 31"24 + 7" = 930 + 7"для наступного дня" = 937 параметрів

Results

Результати

Blue indicates actual consumption, and Red indicates forecast consumption (The numbers are normalized, so they are smaller than real ones).

Синім позначено реальне споживання, а Червоним прогноз споживання (Числа нормалізованні тому менші за реалні).

Technologies

Технології

The project uses Python (PyTorch) for training and C99 for the deployment stage.

Проєкт використовує Python (PyTorch) для навчання та C99 для етапу впровадження.
